# Runtime data

This directory contains local inputs, outputs, large assets, caches, and batch
state. Its generated subdirectories are ignored by Git.

- `downloads/`: incoming audio files
- `processed/`: generated audio before successful delivery cleanup
- `batch_jobs/`: pending batch manifests and selections
- `transcripts/`: transcripts and recommendation records
- `temp/`: temporary mixing and transcription files
- `bgm/`: extracted BGM files
- `models/`: local Whisper models
- `季刊配乐.zip`: the local full music archive
